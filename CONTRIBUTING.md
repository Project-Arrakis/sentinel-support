# Contributing

Thanks for your interest in improving the Arrakis Control Panel Discord
bot community experience.

## What This Repository Is For

This repository is the **public support, Issues, Discussions,
documentation, and release-information** surface for the ACP Discord bot.
It does not contain the bot's application source code — see `README.md`
for why, and where feedback goes instead.

## How to Contribute

- **Bug reports, feature requests, compatibility reports, documentation
  issues:** use the issue forms under "New Issue". See `SUPPORT.md` for
  what makes a good report.
- **Questions and general discussion:** use
  [Discussions](../../discussions).
- **Documentation fixes for files that live in this repository** (this
  README, `SECURITY.md`, `SUPPORT.md`, issue form wording): pull requests
  are welcome. Keep changes focused and explain the "why" in the PR
  description.
- **Security vulnerabilities:** do not open a public issue or PR — see
  `SECURITY.md`.

## Code Contributions

This repository does not accept pull requests containing ACP application
source code (bot logic, WebUI, adapter code) — that code is maintained in
a separate, non-public engineering repository with its own review,
testing, and security-gate process. If you have a code-level fix or idea,
open a Feature Request or Bug Report here describing it; the ACP team will
evaluate it and, if accepted, implement it internally.

## Code of Conduct

Be respectful. Assume good faith. Off-topic, abusive, or spam content will
be removed and may result in the author being blocked.
